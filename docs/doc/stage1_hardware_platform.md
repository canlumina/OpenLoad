# 阶段1-1：硬件平台确定

## 概述
确定STM32F103ZET6 Bootloader项目的硬件平台规格和外设配置。

## 主控芯片规格

### STM32F103ZET6
- **内核**：ARM Cortex-M3，72MHz最大主频
- **Flash**：512KB (0x08000000-0x0807FFFF)
- **SRAM**：64KB (0x20000000-0x2000FFFF)
- **封装**：LQFP144引脚
- **工作电压**：2.0V-3.6V
- **温度范围**：-40°C ~ +85°C

## 外设资源配置

### 串口通信
- **UART1**：调试和IAP通信
  - TX: PA9 (引脚68)
  - RX: PA10 (引脚69)
  - 波特率: 115200bps
  - 格式: 8N1

- **UART2**：ESP8266通信
  - TX: PA2 (引脚16)
  - RX: PA3 (引脚17)
  - 波特率: 115200bps
  - 格式: 8N1

### SPI通信
- **SPI2**：W25Q64外部Flash
  - SCLK: PB13 (引脚52)
  - MISO: PB14 (引脚53)
  - MOSI: PB15 (引脚54)
  - CS: PB12 (引脚51)
  - 最大速度: 18MHz

### GPIO配置
- **按键输入**：
  - KEY1: PE4 (引脚3) - 上拉输入
  - KEY2: PE3 (引脚2) - 上拉输入
  - KEY_BOOT: PE2 (引脚1) - 上拉输入

- **LED指示**：
  - LED_POWER: PB5 (引脚91) - 电源指示
  - LED_STATUS: PE5 (引脚4) - 状态指示
  - LED_ERROR: PB4 (引脚90) - 错误指示

- **ESP8266控制**：
  - ESP_EN: PC13 (引脚7) - 使能控制
  - ESP_RST: PC14 (引脚8) - 复位控制
  - ESP_GPIO0: PC15 (引脚9) - 启动模式控制

## 时钟系统配置

### 主时钟源
- **外部晶振**：8MHz HSE
- **系统时钟**：72MHz SYSCLK
- **AHB时钟**：72MHz HCLK
- **APB1时钟**：36MHz PCLK1
- **APB2时钟**：72MHz PCLK2

### PLL配置
```
HSE = 8MHz
PLL = HSE × 9 = 72MHz
SYSCLK = PLL = 72MHz
HCLK = SYSCLK = 72MHz
PCLK1 = HCLK / 2 = 36MHz
PCLK2 = HCLK = 72MHz
```

## 外部器件规格

### W25Q64外部Flash
- **容量**：64Mbit (8MB)
- **电压**：2.7V-3.6V
- **接口**：SPI (最大104MHz)
- **擦除**：4KB扇区 / 32KB块 / 64KB块
- **编程**：页编程256字节
- **寿命**：10万次擦写循环

### ESP8266 WiFi模块
- **型号**：ESP8266-12F
- **电压**：3.0V-3.6V
- **接口**：UART AT指令
- **频段**：2.4GHz 802.11 b/g/n
- **功耗**：待机<1mA，工作80mA

## PCB设计要求

### 电源设计
- **主电源**：3.3V/1A线性稳压器
- **备用电源**：3V纽扣电池（RTC）
- **电源滤波**：π型滤波 + 去耦电容

### 晶振电路
- **主晶振**：8MHz，20pF负载电容
- **RTC晶振**：32.768KHz，12.5pF负载电容

### 复位电路
- **复位IC**：监控3.3V电源
- **复位按键**：手动复位功能
- **看门狗**：硬件看门狗保护

## 硬件调试接口

### SWD调试接口
- SWDIO: PA13 (引脚72)
- SWCLK: PA14 (引脚76)
- nRST: NRST (引脚14)
- GND: GND
- VCC: 3.3V

### JTAG接口（可选）
- TDI: PA15 (引脚77)
- TDO: PB3 (引脚89)
- TMS: PA13 (引脚72)
- TCK: PA14 (引脚76)

## 验证标准
1. 主控芯片能正常启动和运行
2. 串口通信正常，波特率准确
3. SPI通信稳定，读写W25Q64正常
4. GPIO功能正常，按键和LED工作
5. 时钟系统稳定，频率准确
6. 调试接口正常，能够下载调试
