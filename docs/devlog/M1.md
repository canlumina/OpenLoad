## 2. 关键架构决策

### 接口先行 + 链接段聚合

所有平台相关操作走 `*_ops_t` 接口, 用户实现后通过 `OL_*_REGISTER` 宏注册到链接段:

```c
OL_IO_DEV_REGISTER(console, &g_console_dev);     /* → .ol_io_devs */
OL_FLASH_DEV_REGISTER(internal, &g_internal);    /* → .ol_flash_devs */
OL_CMD_REGISTER("help", "...", cmd_help);        /* → .ol_cmds */
OL_RECEIVER_REGISTER(xmodem, &ol_xmodem_recv);   /* → .ol_receivers */
```

框架启动遍历各段定位已注册对象, 不依赖运行时注册函数. 平台移植只改实现, 不动框架.

### STAGING 升级策略

`download` 分区在外部 W25Q64, `app` 在内部 STM32 Flash:

```
Receiver → download (W25Q64)
            ↓ verify
            ↓ erase app
            ↓ copy
            ↓ re-verify app
          jump app
```

断电窗口仅在 erase+copy 阶段, 失败 staging 仍完整. M2 之后再上 BACKUP / DUAL_BANK.

### 编译期裁剪

`openload_config.h` 用 `#define` 控制功能开关; CMake 端用 `option()`. 用户工程层覆盖默认值:

```c
#define OPENLOAD_ENABLE_XMODEM      1
#define OPENLOAD_ENABLE_XMODEM_1K   1
#define OPENLOAD_ENABLE_YMODEM      0   /* M2 */
#define OPENLOAD_ENABLE_HTTP_OTA    0   /* M2 */
```

未启用模块 0 字节占用.

## 3. STM32F103 参考实现

```
ports/stm32f1/
├── include/
│   ├── port_stm32f1.h
│   └── port_uart1.h
└── src/
    ├── board_init.c          /* port_stm32f1_init: 总入口 */
    ├── port_sys.c            /* ol_sys_ops: tick/reboot/jump */
    ├── port_io_uart.c        /* UART1 console io_dev */
    ├── port_flash_int.c      /* STM32F1 内部 flash dev */
    └── port_flash_w25q64.c   /* W25Q64 SPI 外部 flash dev */
```

布局:

| 区域 | 起始 | 大小 |
|---|---|---|
| boot (STM32 内 Flash) | `0x08000000` | 64 KB |
| app (STM32 内 Flash) | `0x08010000` | 448 KB |
| download (W25Q64) | `0x000000` | 512 KB |

UART1 用 `DMA1_Channel5` circular RX + IDLE 中断 → ringbuf, TX 阻塞.

## 4. 踩坑记录

### 4.1 链接器 GC 把注册对象优化掉

**症状**: 所有 `OL_*_REGISTER` 静态变量无外部引用, GNU ld 默认 `--gc-sections` 把它们当死代码丢掉, 运行时 `.ol_flash_devs` / `.ol_io_devs` 链接段为空, 找不到设备.

**修复** (commit `6320623`): example CMakeLists 链接 openload 静态库时用 `--whole-archive` 包裹:

```cmake
target_link_libraries(${PROJECT_NAME} PRIVATE
    "-Wl,--whole-archive"
    openload
    openload_port_stm32f1
    "-Wl,--no-whole-archive"
    STM32_Drivers
)
```

注释里写清楚为什么不能去掉, 否则后人删除时整个框架静默失效.

### 4.2 XMODEM 升级链路对齐 / 重入 (commit `76dd1a4`)

末端 install 流程几个坑一起暴露:

- **erase 对齐**: ol_part_erase 要求按 sector_size 对齐, 但 image total 是任意字节. 修复: `(total + sector - 1) & ~(sector - 1)` 向上取整再夹到 partition.size 内. 详见 `openload/core/updater.c:88-91`.
- **W25Q64 page write 跨页**: SPI flash 单次 page program 不能跨 256B 边界. driver 内部已处理但要保证 caller 传的 len/off 合理.
- **UART RX 中断重入**: console io_dev 的 ringbuf write 与读端同时访问, 加 PRIMASK 关全局中断保护.

## 5. 端到端验收

工具: Tera Term + ST-Link.

```
1. cmake --build build/Debug
2. STM32CubeProgrammer 烧 openload_bootloader.bin → 0x08000000
3. 复位, 串口看到:
     [I] OpenLoad 0.1.0-m1 starting
     [I] press button or send any char in 3000 ms to enter CLI
4. 按任意键 → CLI
5. update xmodem download app
6. Tera Term: File → Transfer → XMODEM → Send <firmware>.bin
7. 看到:
     [I] verify staging download
     [I] erase target app ...
     [I] copy ... bytes -> app
     [I] verify target
     [I] install ok
8. jump app → 新 App 启动
```
